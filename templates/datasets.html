💡 How to Use Uploaded CSVs in Practice Using Just the File Name
1. In SQL Practice Editor

Query directly by filename or clean table name:

SELECT * FROM sample_employees.csv LIMIT 5;
SELECT * FROM sample_employees;
SELECT * FROM 'sample_employees.csv';
2. In Python Practice Editor

Files are placed directly in your execution directory:

import pandas as pd
df = pd.read_csv('sample_employees.csv')
print(df.head())
3. In PySpark Editor

Read directly via SparkSession:

df = spark.read.csv('sample_employees.csv', header=True)
df.show(5)
